How it works

Three steps. That's it.

Install once, and every Instagram post gets a live dislike counter right next to the like button.

1
📦

Install the extension

Add Dislike Button for IG to Chrome from the Web Store in one click. No account or sign-in needed.

2
👎

See the button everywhere

Open any Instagram post. A dislike button appears right in the action bar, next to the like button.

3
📊

Vote & see the count

Click to dislike. The counter updates in real time and is shared with every other user of the extension.

Privacy first

Zero personal data. Seriously.

Inspired by Return YouTube Dislikes, built with the same privacy-first principles.

🙈

No personal data collected

No name, email address, Instagram username, or browsing history. We have no idea who you are and we like it that way.

🎲

Anonymous UUID only

Your identity in our system is a randomly generated UUID stored locally in your browser. It contains no personal information.

🛡️

IP address never stored

Your IP is hashed with SHA-256 before touching our database, used only for rate limiting, and is never linked to your identity.

🗑️

Full data deletion

One click in the extension popup permanently erases your UUID and all associated votes from our servers. GDPR-compliant.
